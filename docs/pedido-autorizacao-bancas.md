# Pedido de autorização para uso de questões de provas

Modelo para enviar a cada banca antes de usar questões de provas dela no app.
Preencha os campos entre colchetes. Na FGV, o contato pelo site é
<https://conhecimento.fgv.br/contato-0> (os termos de uso da plataforma estão
em "Termos de Uso", no rodapé). Guarde a resposta por escrito: o texto e a
data dela vão no campo `authorizationNote` de cada questão oficial.

Antes de enviar, vale mostrar este modelo ao advogado da empresa.
